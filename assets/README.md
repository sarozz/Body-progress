# Assets

Replace these placeholders with real images before publishing:

- `icon.png` — 1024×1024 app icon
- `adaptive-icon.png` — 1024×1024 Android adaptive icon foreground
- `splash.png` — splash logo (PNG with transparent background)

For local development with Expo Go you can run without these — Expo will use
default placeholders and only complain at build time. For a production EAS
build they are required.
